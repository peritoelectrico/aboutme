When to Use This Tool

🔄 Motor Upgrade / Swap
Replacing an aging induction motor with a servo motor, or substituting a discontinued model with a current equivalent. Use this tool to verify the new motor delivers the same gearbox output torque and linear performance.
⚙️ Gearbox Ratio Change
The original gearbox is obsolete, out of stock, or needs rerating. This tool proposes an ideal new ratio and calculates what ratio you actually need to match the original output torque and linear speed.
📐 Linear Motion Systems
Rack-and-pinion drives, ball/lead screws, belt & pulley conveyors, winches — any application converting rotary motor output into linear travel. The Rack Scale field is the linear distance per gearbox revolution.
🏭 OEM Replacement (MRO)
Equipment is end-of-life or the OEM no longer supports it. Validate a cross-brand replacement maintains equivalent thrust force, travel speed, and gearbox catalog torque rating with the correct service factor.
✔ Handles both Induction and Servo motors with correct torque-curve physics
✔ Servo sizing uses rated torque (constant-torque region), not max-speed torque
✔ Service Factor applied only to gearbox catalog rating — does not inflate delivered torque
✔ New Rack Scale auto-calculated to preserve original linear speed with the new ratio
✔ Compatible with Studio 5000 Axis Scaling (Conversion Constant)

What is Base Speed?

Base Speed is the highest motor RPM at which the motor can still deliver its full rated torque. Below this point, torque is constant (limited by current). Above it, power is constant and torque drops as speed increases.

Calculated as: Base Speed = (9550 × PkW) / Trated
Use the rated torque from the motor datasheet for sizing gearboxes — not the torque at max speed.
