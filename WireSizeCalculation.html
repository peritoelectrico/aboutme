System Parameters

Voltage drop uses the actual current per NEC Ch.9 Table 8 (K = 12.9 Cu / 21.2 Al Ω·cmil/ft @ 75°C, uncoated). Ampacity sizing follows NEC 310.16 + 110.14(C) + 240.4(D). For inductive loads (low PF) use NEC Ch.9 Table 9 (R & X).

Why this tool targets 3% only
NEC 210.19(A) IN 4 and 215.2(A)(1) IN 2 recommend ≤3% on the branch circuit OR feeder, and ≤5% combined (feeder + branch). These are informational, not mandatory. This tool sizes to the conservative 3% target so the result is safe whether the run is a feeder or a branch. The 5% dashed line on the chart is shown only as the absolute upper limit of the combined system — do not design to it.
AC 3-phase motors
3% at running FLA is the standard target (NEMA MG-1 / IEEE 141). Motor starting inrush (LRA, typically 6–8× FLA) is a separate analysis and may briefly exceed 10% — if a soft-starter / VFD is not used, verify motor terminal voltage stays ≥90% of nameplate during start. This calculator addresses running current only.
