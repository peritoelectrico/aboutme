Enter Y values for each X position. The system calculates the slope for each consecutive section between increments. Increment width follows the current scale (10 steps total: 1 on a 10×10 scale, 10 on a 100×100 scale).
Drop Test Mode. The X axis is split into 10 fixed segments based on the current scale (segment width = 1). The test always starts at (0, 0). For each segment, enter the measured X (auto-clamped to that segment's range) and the measured Y. Y is optional — leave blank to skip that segment; missing segments are filled by linear interpolation between your filled points (and extrapolation past the last one) so we always report all 10 segment slopes from 0 to 10.
